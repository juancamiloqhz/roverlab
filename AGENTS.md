## Agent skills

### Issue tracker

Issues and specs use local Markdown under `.scratch/<feature>/`. Before creating, fetching, or updating them, read `docs/agents/issue-tracker.md`.

### Triage labels

Use the five default triage roles. Before assigning or interpreting triage state, read `docs/agents/triage-labels.md`.

### Domain docs

Use a single-context layout: root `CONTEXT.md` and `docs/adr/`. Before exploring the codebase or proposing domain changes, read `docs/agents/domain.md`.
